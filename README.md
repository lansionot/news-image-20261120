# Sum up 20 November's world news in one image

make.fun bounty: `news-image-20261120`
— "Sum up 20 November's world news in one image"

A 1024×1024 newspaper front page for Friday 20 November 2026.
`main.py` (Python 3, stdlib only, no network) deterministically copies
`entry.png` to `/output/entry.png`. Repeated runs write identical bytes.

## Run

```sh
python3 main.py
# writes /output/entry.png (1024x1024 PNG, 919,877 bytes)
```
